# -BANKLOAN-ANALYSIS-
🏦 Bank Loan Case Study – Project Description
📌 Objective:
The Bank Loan Case Study aims to analyze customer loan applications to identify patterns in loan approvals and defaults. The project helps financial institutions optimize their lending strategies and minimize risks by understanding key factors affecting loan repayment behavior.

📊 Key Insights & Analysis:
1️⃣ Loan Approval Analysis
Understanding factors affecting loan approvals
Identifying key borrower attributes influencing loan decisions
2️⃣ Risk & Default Prediction
Analyzing past loan defaults based on customer demographics
Predicting high-risk applicants using statistical & machine learning models
3️⃣ Customer Segmentation
Grouping borrowers based on creditworthiness
Analyzing income, credit score, and past loan behavior
4️⃣ Loan Amount & Tenure Trends
Loan amount distribution by borrower category
Interest rate & repayment tenure insights
🛠️ Tech Stack:
Data Handling: Python (Pandas, NumPy)
Data Visualization: Matplotlib, Seaborn
